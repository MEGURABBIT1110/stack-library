Stack Library

画面のたたき台

本棚を眺める。気になる一冊を手に取る。必要な情報だけが見える。実装前の方向性確認用ワイヤーフレーム。

本棚では、書影だけ タイトル・著者・状態・価格・蔵書番号は表示しない。並び順もユーザーに管理させない。
手に取ってから、情報を見る タイトル、著者、技術領域、キーワード、ISBN、任意のメモを詳細で確認する。
登録は、ISBNから ISBNで書誌情報と書影を取得。取得できないときだけ、書影を補正・登録できる。
